# Comparador de Balancetes: Betha x TCE

Este documento contém as informações descritivas da solução de **Comparação de Balancetes (Betha vs. TCE)**. O objetivo deste texto é servir como base (copy) para a criação de uma nova aba ou página no seu site institucional, anunciando este serviço para seus clientes (prefeituras, câmaras e contadores públicos).

---

## 🎯 Título Sugerido para a Página
**Auditoria e Conciliação Contábil Automatizada: Betha x TCE**

## 💡 O que é a Solução?
O Comparador de Balancetes é uma ferramenta desenvolvida para automatizar e simplificar a rotina de conciliação contábil do setor público. Ele cruza os dados extraídos do sistema **Betha** com os dados enviados ao **Tribunal de Contas do Estado (TCE)**, identificando instantaneamente qualquer inconsistência ou diferença de valores.

## 🚀 Principais Funcionalidades

1. **Comparação Inteligente e Automatizada**
   - **Modo Analítico e Sintético:** Flexibilidade para analisar os dados em diferentes níveis de detalhamento.
   - **Filtro de Saldos:** Permite a conciliação baseada tanto no *Saldo Atual* quanto no *Saldo Anterior*.

2. **Detecção Precisa de Divergências**
   - **Diferenças de Saldo:** O sistema calcula matematicamente as variações entre os registros do Betha e do TCE, destacando os valores divergentes em centavos.
   - **Máscaras Sem Correspondência:** Identifica imediatamente contas (máscaras/contas correntes) que foram cadastradas em um sistema, mas esquecidas no outro.

3. **Geração de Relatórios (Exportação em CSV)**
   A ferramenta entrega resultados prontos para o trabalho do contador, incluindo:
   - Relatório completo de Comparação.
   - Relatório exclusivo de Diferenças.
   - Relatório de Máscaras Órfãs (exclusivas do Betha ou exclusivas do TCE).

4. **Tratamento e Normalização de Dados**
   - Conversão automática de notações científicas e limpeza de caracteres indesejados.
   - Padronização de Máscaras Contábeis e Contas Correntes para garantir um cruzamento exato (matching perfeito).

5. **Segurança e Licenciamento Multi-Entidade**
   - Acesso controlado via chaves de licença exclusivas por ente público (Ex: Prefeituras, Câmaras, Fundos).
   - Suporte multi-usuário com processamento isolado (sem conflito de dados entre clientes enviando ao mesmo tempo).

## 📊 Benefícios para a Gestão Pública (Por que contratar?)
- **Economia de Tempo:** O que levava horas ou dias de conferência manual no Excel é feito em poucos segundos.
- **Redução de Riscos (Malhas do TCE):** Evite multas e apontamentos do Tribunal de Contas enviando os dados 100% conciliados.
- **Transparência e Precisão:** Segurança absoluta de que o saldo no sistema de gestão é o mesmo saldo prestado contas ao TCE.
